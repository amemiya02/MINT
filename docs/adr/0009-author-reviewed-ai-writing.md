# 内置写作助手，沿用作者的模型或 Agent

写作助手是内置文档操作：空白页提供直接起草和交代写作任务两个入口，已有稿件支持选区指令和按需展开的会话。作者首次使用时连接自己的模型服务、本地模型或兼容的外部 Agent，之后沿用所选连接；界面说明各连接支持的能力。

发送前展示任务材料和接收方，由作者决定是否附上其他文件或允许在工作文件夹中查找资料。两条接入路径共用改稿与审阅方式。查看改动时默认呈现排版效果，也可展开 Markdown 源码差异。应用到稿件的修改进入共享撤销历史。

支持文件写入的外部 Agent 在任务副本中起草。MINT 从副本提取文档修改以及新建、移动和重命名操作，展示依赖关系，例如一处回链所指的文件仍待新建。未纳入 Git 的普通文件夹及未保存稿件同样适用。作者可以从下一条消息起更换连接，也可以授权另一连接使用同一版材料重试，并排比较两个方案、选取其中的修改。

写作任务默认由作者发起。行内续写与自动校对分别开关；淡色续写可用 Tab 接受、Esc 忽略，继续输入即让位于作者。只读审阅产生批注，可锚定句子、表格单元格、公式或图片。作者可积攒多条批注后一起送审；汇总视图区分待处理、已解决和失去原位置的批注，保留最初圈选的内容。

作者可以用斜杠调用内置或自存的写作技能，并为当前工作文件夹设定写作偏好。发送前展示本次采用的技能、偏好和工具。使用 Zotero、MCP 等外部工具时按任务授权。

连接设置区分模型服务、本地模型和已安装的 Agent，提供预设、发现和手动添加入口。作者可以用示例文字试写，看到实际验证过的对话、流式生成、修改建议和多文件能力。

运行中的任务可以收起，作者仍可编辑和切换文档。进展说明当前读取的材料、已生成的建议及等待的授权。停止、断网或额度用尽时，完整建议保留供审阅，未完成的文字留在会话中；作者可以重试或改用其他连接。材料超出容量时展示实际范围，由作者选择摘录、分批或摘要；追加未授权材料时说明用途，更换接收方时重新展示发送范围。

长稿审阅提供改动分布、文件与章节导航、待审筛选及渲染与源码对照。按章节批量接受只处理待定建议，保留此前的拒绝和留评，并支持一次撤销。已拒建议可从审阅记录找回。

普通会话在本机保存材料清单、建议、审阅决定和阅读位置。重新打开时标出因原稿变化而需要重新比较的建议，其余建议可继续审阅。恢复会话后由作者决定是否继续调用模型。作者可以使用临时会话，或删除某次任务及其副本。

发送前可选「只点评」「先预览」或「直接改」。审阅文章默认只点评，空白页生成初稿默认直接生成可编辑草稿，改写已有选区默认先预览。作者明确要求直接改时，发送按钮显示本次选择，一次发送即授权。作者可以为指定工作文件夹中的特定技能记住选择，每次发送前仍可更换。

直接改仅应用任务范围内、与当前稿件相容的修改。遇到新文件或手改冲突时，完成其余独立修改，将越界或冲突部分留给作者决定；新建文件失败时，同时暂缓指向该文件的新链接。

任务完成后以轻提示汇总实际改动，提供查看和撤销入口。任务记录支持整次或逐处撤回，保留作者后来写的内容；同一处又有编辑时，让作者比较并选择。

AI 以屏幕上的当前稿件为起点，沿用该稿件的自动或手动保存设置。空白页生成未命名初稿，作者保存时选择位置。明确要求批量更新文件的任务在发送前列明将写入的文件，完成后可整次撤回。

基于材料写作时，作者可以从结论跳回来源文件和原文片段，缺少依据的内容标记为待核对。依据标记保存在审阅界面；作者要求正式引用时才将引用写入 Markdown。

作者可以设置全局默认连接，并按续写、整章审阅或多文件任务等动作覆盖。发送前展示实际接收方；本地连接离线时保留输入，由作者决定是否转到云端。只返回文本的模型也能改稿：针对已知选区的明确替换由 MINT 生成差异，按本次方式预览或应用。无法明确解释为替换的回复保留在会话中，供作者选择插入。

工具授权以作者交代的结果为界。查阅已授权文库和修正文内引用属于稿件任务；修改外部文库或向其他服务发送稿件时，应让作者看到动作、目标与影响。若作者发起任务时已明确授权这些具体操作，执行时沿用该授权。

外部 Agent 沿用自己的登录。MINT 直连模型服务所需的 API 密钥保存在系统凭据库，设置仅展示连接名、服务地址和密钥尾号；凭据库不可用时可仅在本次使用。断开一个连接保留已有稿件及相关审稿记录。

编辑时优先响应作者输入，合并连续打字间的短暂停顿，每个编辑窗口最多保留一个有效的续写请求。继续输入或切换文档会使旧建议失效，迟到的回复不改变正文或光标。作者主动发起的长任务可以在后台运行，也可以停止。

短改和启用的续写沿用当前连接。处理整本书、多轮工具调用或多模型比较时，发送前展示材料规模、连接及已知或计划的调用次数；有可靠的用量或价格信息时提供估算。作者可以给任务设置上限，到达上限即暂停并保留结果。

临时会话在关闭前可审阅和撤回。关闭入口说明已写入的正文会保留，关闭后无法按该任务一键撤回；关闭时清除本机会话、材料副本及任务审阅记录，文档继续沿用原有的本地版本历史。连接详情说明云端服务的留存规则。

外部 Agent 的权限说明以可验证的实际访问范围为准。MINT 应区分已选材料与 Agent 自身可访问的文件和工具，提供仅传选中文本或隔离运行的接入方式。沿用 Agent 原有权限时，作者在首次连接或权限扩大时决定；后续任务沿用已授权的范围。

作者可以拖入、粘贴或从 Zotero 选择材料。材料卡片显示实际发送的页码、图像区域或题录；纯文本连接可使用图注或提取的文字，需要识别图像细节时可改用支持图像的连接。

普通会话保留实际使用的摘录和出处。来源改版后，原稿的依据仍可回到当时的摘录，作者可对照新版或主动发起核对，集中查看受影响的陈述。资料更新本身不调用模型；临时会话仍遵循关闭时的清理约定。

作者可把一次纠正记为本次任务、当前工作文件夹或个人默认的写作偏好。优先采用本次明确要求，其次采用工作文件夹约定，再采用个人默认。日常纠错无需逐次确认是否记忆。

作者可将成功任务保存为写作技能，保留步骤与结果格式，将原材料替换为下次调用时选择的材料。技能可在保存前试跑，也可导出分享。导入者可查看材料范围、所用工具和默认改稿方式，使用自己的连接及授权执行。

默认界面以正文为主。空白页可直接起草，已有稿件选中文字后显示「问 AI」，短任务在就地指令框完成。发送处用一行列明动作、范围和接收方，例如「直接改 · 当前选区 · 本地模型」，每项均可调整。多轮讨论或集中审阅时展开右侧栏；技能、历史和连接管理按需打开。

一批批注保留逐条对应的答复、修改或缺少的材料。直接改完成后汇总已修改和仍需决定的事项；先预览按原文顺序审阅。只有答复的批注也可由作者标记解决。

作者可以选取回复的一部分，插入光标处、替换发起任务时的选区，或另存为新稿。操作前标明目标，切换分栏后仍显示原稿名称；原选区发生变化时先比较差异。

短任务随发起文档，跨文档任务归属工作文件夹。侧栏默认显示当前稿件的会话，全部任务入口可查看后台进度、待决定事项及历史结果。后台完成以轻提示告知，作者点开才返回相应位置；每个待决定事项提醒一次。

审阅支持用键盘逐处导航、接受、拒绝和留评，处理后定位下一处待审项，退出时恢复原阅读位置。窄窗口上下排列前后版本，增删附文字标识，读屏报告改动类型、当前位置与总数。

## 写作体验验收

1. **快改一段**。已有连接且目标明确时，作者选中一段，输入「缩短一半，直接改」，按回车即应用修改。光标留在稿件，可继续输入，也可一键撤销此次改动。
2. **根据材料起草**。作者拖入两份材料，在指令框交代任务，发送后得到可编辑的初稿。点选有依据的结论，可回到对应材料的原文片段。
3. **审阅长稿**。作者全程使用键盘即可逐处决定，也可一次接受本节剩余的待审建议；退出审阅后回到进入时的阅读位置。
