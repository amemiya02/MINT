# 文档链接保存在原文，版本历史保存在本机应用数据目录

为便于在其他编辑器中阅读和维护文档，MINT 创建文档或章节链接时默认写入标准 Markdown，例如 `[实验结果](报告.md#实验结果)`。沿用双链语法的用户可以按工作文件夹开启识别，让已有的 `[[报告]]` 支持跳转、预览和反向链接；打开文件夹不会改写原文。

版本历史保存在本机应用数据目录，使工作文件夹继续只包含用户自己的文件。用户可以比较两个版本，恢复整篇文档，也可以只取回一处改动并保留当前稿件的其他内容。

在 MINT 内移动文档或为其改名时，用户可以查看受影响的引用，选择仅移动，或一并更新链接。更新保留链接的显示文字和章节锚点；双链语法遇到同名目标时由用户选择。撤销这次文件操作会同时还原路径和本次改动的引用。

从版本历史取回一处改动或恢复整篇文档，都会作为一次可撤销的编辑应用到当前稿件。整篇恢复前先保留当前版本，以便自动保存后仍能找回恢复前的稿件。
