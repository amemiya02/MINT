# 通过可选插件扩展本地写作工具

MINT 支持用户安装第三方插件，让文献引用、看板、幻灯片等专门工具按需加入写作界面。双文档并排、章节跳转和文件操作撤销属于内置文档操作。这项选择使默认界面保持精简，同时也让插件作者成为 MINT 在演进扩展接口时需要考虑的使用者。

知识管理沿用普通工作文件夹。用户可以在其他编辑器里继续读写原文，直接打开一个文件夹也无需先将文档导入 MINT。

第三方插件面向 MINT 自己的扩展接口开发，可提供命令、侧栏视图和文档操作。由 MINT 定义文档操作的边界，便于维护源码保真；已有 Textus 插件需要适配。用户在设置中发现、安装、停用和卸载插件。

安装界面按用户能理解的动作说明插件所需的权限，例如读取当前文档、修改当前工作文件夹中的 Markdown 或连接指定服务。更新沿用已授予的权限。新版要求额外权限时，用户可以授权更新，也可以继续使用已安装的版本。
