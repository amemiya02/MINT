# Domain docs

MINT has one domain glossary and one set of architecture decision records
(ADRs) shared by the desktop app and editor package.

Before exploring an area, read the root `GLOSSARY.md` and the relevant
decisions in `docs/adr/`. Use the glossary's terms in issues, proposals,
tests, and code. If a concept needs a new term, raise it for `/domain-modeling`.

When a proposal conflicts with an ADR, cite the decision and explain why it
merits reconsideration. If a domain document is missing, continue with the
available material. `/domain-modeling` records terms and decisions as they
are resolved.
